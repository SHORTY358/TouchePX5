# PS5-игры на Windows: разбор видео и проверка источников

Проверено 21 октября 2026 года. Это обзор основных найденных проектов и
проверяемых свидетельств, а не обещание охватить буквально весь интернет.
Сторонние результаты ниже не воспроизведены на этом ПК.

## Главный вывод

PS5-игры уже запускают на Windows в существующих открытых проектах.
Ближайшая разумная цель — повторить один опубликованный рабочий сценарий
в свежем KytyPS5 и SharpEmu, прежде чем продолжать расширять собственный
экспериментальный рендерер TouchePX5. GTA VI остаётся отдельной, непроверенной целью.

Для нашего ПК внешняя цепочка PS5 → Wine/Proton не нужна. Нужна
**Windows → KytyPS5/SharpEmu → PS5-версия игры**. Получать рабочий стол или
главное меню самой PS5 для этого не требуется.

[сообщение о демонстрации с KytyPS5](https://www.reddit.com/r/PS5_Jailbreak/comments/1x86n6w/ps5_emulator_running_inside_the_freaking_ps5/),

[патчи PS4/PS5](https://github.com/illusionyy/ps-patch-system),
[PS5SX2](https://github.com/Swordpdf/PS5SX2).
Сообщение о демонстрации — пересказ, не независимый технический аудит.

## Практические кандидаты

| Проект | Подход и свидетельства | Решение для нас |
| --- | --- | --- |
| [KytyPS5](https://github.com/KytyPS5/KytyPS5) | C++, Windows/Linux; перевод системных вызовов и графики в Vulkan, современные 2D/3D-игры; системные LLE-модули не требуются | Первый кандидат для повторения результата из ролика |
| [SharpEmu](https://github.com/sharpemu/sharpemu) | C#, Windows/Linux/macOS; родственная база нашего проекта; отдельные отчёты о совместимости с точной сборкой | Обязательный параллельный ориентир на том же наборе файлов игры |
| [AnyPS5](https://github.com/boykopovar/AnyPS5) | Заранее преобразует исполняемый файл в Windows PE/Linux ELF, предоставляет замены системных библиотек; графический перевод всё равно необходим | Альтернативный путь для конкретных поддерживаемых игр, не универсальный конвертер |
| [chenxiao07/KytyPS5](https://github.com/chenxiao07/KytyPS5) | Ветка с отдельными оптимизациями Demon's Souls, собственными релизами и ограничениями версий игры | Рассматривать после первого обычного запуска; не подменять ею совместимость всех игр |
| [TheCruZ/KytyPS5-GTA](https://github.com/TheCruZ/KytyPS5-GTA) | Ветка для исправления проблем GTA V и передачи исправлений в основной проект | Смотреть при работе с PS5 GTA V; название GTA не означает проверенную GTA VI |
| [prosper](https://github.com/mattias800/prosper) | C++20, преимущественно Linux; прямое выполнение x86-64, системные библиотеки, AGC → Vulkan 1.4; подробные маршруты отдельных игр | Полезен для исследования и сравнения ошибок. В README отсутствует выдача лицензии: переносить код в наш проект без разрешения нельзя |

Дополнительные проверенные направления:

- [RPCSX](https://github.com/RPCSX/rpcsx) описывает себя как экспериментальный
  PS4/PS5-эмулятор для Linux. Подтверждённого удобного маршрута PS5 → Windows
  для нашей задачи при этой проверке не найдено.
- [Исходный InoriRus/Kyty](https://github.com/InoriRus/Kyty) указывает простые
  PS4-игры и PS5-homebrew. Его возможности нельзя путать с новым KytyPS5.
- [Obliteration](https://github.com/obhq/obliteration) — переписанное ядро PS4
  и виртуализация её системного ПО; это не готовый способ запускать PS5-игры.
- [shadPS4](https://github.com/shadps4-emu/shadPS4) — эмулятор PS4, полезный
  архитектурный источник, но не замена PS5-эмулятору.

## Конкретные игры и сборки вместо общих обещаний

### Hollow Knight — ближайшая проверяемая цель

[Отчёт KytyPS5 #1479](https://github.com/KytyPS5/KytyPS5/issues/1479):
PS5-версия `PPSA34971`, сборка `KytyPS5-2026-10-12-df5b9b9`, Windows 11,
i5-10400F / GTX 1660 Super / 16 ГБ DDR4. Автор сообщает о двух часах игры
без замеченных графических/звуковых ошибок и вылетов. Сохранение нужно отдельно
проверить через скамью и штатный выход. Это свидетельство одного пользователя,
не гарантия прохождения целиком.

[Отчёт SharpEmu #299](https://github.com/sharpemu/sharpemu-site/issues/299):
`PPSA34971`, версия игры `1.000.002`, сборка `5052fae`, Windows,
Ryzen 5 7500F / RTX 5060 Ti 16 ГБ. Заявлены играбельность и 60 FPS.
[Карточка игры](https://sharpemu.app/game/PPSA34970/) объединяет
`PPSA34970` и `PPSA34971` и предупреждает о возрасте проверенной сборки.

Эти два независимых проекта дают особенно полезный общий тест. Покупка PC-версии
в Steam сама по себе не создаёт PS5-исполняемый файл для этого теста.

### Demon's Souls и высокие FPS

[chenxiao07 v20261021](https://github.com/chenxiao07/KytyPS5/releases/tag/v20261021)
предназначен для `PPSA01341` версий `01.007.000` и `01.005.000`; в релизе
описаны 1080p-вывод, FSR 3.1 frame generation и исправления конкретных ошибок.
Это быстро меняющаяся специализированная ветка.

У [отдельной сборки ceremony88](https://github.com/ceremony88/KytyPS5-DemonsSouls-FrameGen)
автор публикует примерно 117 выводимых кадров при примерно 58 игровых кадрах
на RTX 4080 / i7-13700K / 32 ГБ. Её DLSS Frame Generation требует RTX 40 или
новее. Исходники указаны отдельным архивом в релизе, а не в основном дереве.
Эти цифры нельзя переносить на GTX 1060 или на другую игру.

### GTA V не равна GTA VI

[Отчёт о GTA V на сайте KytyPS5](https://github.com/KytyPS5/kytyps5.github.io/blob/main/src/content/compat/grand-theft-auto-v-windows.md):
`PPSA04264`, Windows, i5-13600K / Arc B580 / 32 ГБ, режим Performance,
достигнута игра, но определённые ролики вызывают ошибку depth feedback.
Это полезная ступень к RAGE, но не доказательство совместимости будущей GTA VI.

На дату проверки [Rockstar](https://www.rockstargames.com/VI) указывает
**19 ноября 2026** для PS5 и Xbox Series X|S. По найденным источникам
воспроизводимый публичный запуск розничной GTA VI в этих проектах не подтверждён.
До получения самой игры её совместимость и требования предсказать надёжно нельзя.

## Что проверено на нашем компьютере

Локально сейчас обнаружены GTX 1060 3GB, 16 ГБ RAM, драйвер
`32.0.15.8157`. Прямой запрос к установленному Vulkan-драйверу дал
**Vulkan 1.4.312, 204 расширения устройства, без `VK_EXT_mesh_shader`**.
Полный результат: `artifacts/research-video-20261021/vulkan-device.json`.
Версия API не означает наличие всех необязательных возможностей.

Следствия:

- Базовое требование KytyPS5 по Vulkan 1.3 выполнено на уровне версии API;
  нужные конкретной игре расширения нужно проверять по её запуску.
- 3 ГБ видеопамяти — серьёзный возможный предел для тяжёлых игр, но точного
  расхода выбранной игры на этом ПК пока нет.
- Отсутствие mesh shaders может блокировать отдельные графические пути:
  [KytyPS5 #1447](https://github.com/KytyPS5/KytyPS5/issues/1447) показывает
  такой отказ Astro's Playroom на другой карте без этой возможности.
  Этот отчёт нельзя превращать в запрет всех 2D-игр на GTX 1060.
- Откладывать вообще все эксперименты до покупки видеокарты оснований нет.
  Сначала пробуем подходящую игру, затем решаем по наблюдаемому ограничению.
- Linux и отдельный SSD не требуются для первого теста на Windows.

## Почему у нас пока другой результат

Проверенный локальный HEAD: `eb1e504`, ветка `codex/validate-ngs2-outputs`,
репозиторий `Techx3/TouchePX5`. Наш текущий этап — собственная ветка
SharpEmu с проверками отдельных функций, Wolf4SDL и ограниченным запуском
homebrew-рендерера BSP. Последний путь допускает определённые шейдеры и
форматы; он не является общим графическим переводчиком всех PS5-игр.

Кроме того, существующий `C:/Dev/KytyPS5` сейчас на коммите `b531329`
от 9 сентября 2026, а опубликованные выше сценарии Hollow Knight появились
в октябре. Это не доказывает единственную причину прежних неудач, но показывает,
что старый checkout не представляет нынешний upstream.

Инженерная ошибка приоритета — слишком долго расширять учебные сцены без
регулярного сравнения с успешным запуском актуального внешнего проекта.
Исправление: сначала получить общую игру и сравнимые результаты, потом
выбирать, что развивать. Успешные внутренние тесты нельзя пересчитывать в
проценты готовности GTA VI.

## Следующие действия с критериями результата

1. Подготовить отдельные каталоги свежих KytyPS5 и SharpEmu на D, записать
   версии и SHA-256 архивов. Не заменять ими файлы TouchePX5 и не смешивать кэши.
2. Определить доступную законно полученную PS5-версию игры. Первый выбор —
   Hollow Knight `PPSA34971`, желательно версия из отчёта SharpEmu.
   Нужны файлы игры, а не ролик, ярлык, PC-версия или один зашифрованный пакет.
   Подготовленный собственный дамп позволяет играть без работающей PS5 рядом;
   задача получения дампа отдельна от выполнения игры на Windows.
3. Сначала проверить свежий upstream. При неудаче повторить указанную рабочую
   сборку из отчёта. Сохранить лог первого сбоя, изображение, расход RAM/VRAM,
   состояние драйверных возможностей. Отдельно классифицировать неполные файлы,
   программный дефект и ограничение GPU.
4. Провести короткую реальную сессию: управление, звук, смена комнаты,
   сохранение, штатный выход и повторная загрузка. Считать успехом именно
   этот сценарий, а не открывшееся окно или счётчик FPS.
5. Запустить те же файлы в TouchePX5. Если upstream работает, а наша ветка нет,
   выбрать первый существенный сбой для исправления. Если собственная ветка
   сильно отстала, рациональнее развивать свежую базу с переносом полезных
   изменений, чем вручную повторять всё развитие upstream.
6. При необходимости проверить AnyPS5 отдельно. По его
   [инструкции](https://github.com/boykopovar/AnyPS5/blob/main/docs/user/USAGE.md)
   нужен подготовленный ELF и модули; `--windows` выбирает PE, а `--to-intel`
   исправляет найденные AMD-специфичные инструкции, с ограничением для кода,
   сгенерированного игрой во время работы. Это не решение всех несовместимостей.
7. Затем выбирать более тяжёлую игру по свежему отчёту и наличию собственных
   файлов. Demon's Souls — отдельный эксперимент; GTA V — полезный кандидат
   для изучения RAGE. Для каждого этапа сохранять один воспроизводимый маршрут.
8. GTA VI проверять только при наличии доступного исполняемого материала:
   загрузка → меню → корректная сцена → управление → сохранение → длительная
   сессия → оптимизация. Ни дату успеха, ни FPS сейчас не объявлять.

Прямой перенос C++-рендерера в C# не сводится к копированию файлов.
Переиспользуем идеи, форматы, исправления и код с соблюдением лицензий;
выбираем основной рабочий движок по игровому результату.

В этой проверке эмуляторные архивы не запускались, коммерческие игры не
загружались и система не переустанавливалась. Новые данные разбора и локальная
модель распознавания находятся на D; изолированные инструменты занимают
около 489 МиБ. Следующий инженерный приоритет — внешний игровой эталон,
а не очередное расширение сцены BSP.
