# Публичные проекты PS5 на ПК — проверка 8 октября 2026

Проверены поисковая выдача, первичные репозитории, документация совместимости,
конкретные отчёты, последние коммиты и релизы через GitHub API. Это обзор
доступных публичных проектов, а не исчерпывающая проверка всего интернета.
Чужие коммерческие игры локально не запускались. Отчёты разработчиков и
пользователей ниже не являются независимым подтверждением с нашего компьютера.

## Основные проекты

| Проект | Подход и наблюдаемая область | Последний коммит при проверке, UTC |
| --- | --- | --- |
| [SharpEmu](https://github.com/sharpemu/sharpemu) | C#, родное исполнение x86-64, системные функции, Vulkan. Есть общественные отчёты о коммерческих играх. | 07.10, `b02c06181a`, исправления Unity |
| [KytyPS5](https://github.com/KytyPS5/KytyPS5) | C++, Vulkan, развитие Kyty. Заявлены запуски 2D и некоторых 3D игр; есть отчёты с ошибками и логами. | 08.10, `4865dd92ca`, системная функция языка пользователя |
| [prosper](https://github.com/mattias800/prosper) | Слой совместимости PS5→ПК, родное исполнение CPU и перевод графики. Основной исследовательский путь — Linux. | 08.10, `04a07cbe72`, исправление компилятора шейдеров |
| [AnyPS5](https://github.com/boykopovar/AnyPS5) | Перелинковка игры в исполняемый файл Windows/Linux и реализация необходимых библиотек. Это всё равно работа по совместимости системы и графики. | 08.10, `033a46360d`, проверка границ перелинковки |
| [Prosperity](https://github.com/Force67/prosperity) | PS4/PS5; предпочитает низкоуровневое окружение с исходными системными модулями. Linux основной; Windows пока планируется. | 04.10, `2ef9b3b86f`, развёртывание Steam Deck |
| [PS5PCEM](https://github.com/iStark/PS5PCEM) | Zig, Windows, родное исполнение и Vulkan. Публикует ограничения конкретных запусков. | 08.10, `7b9cc37eb1`, пул памяти |

Свежие изменения подтверждают активность, но число коммитов не измеряет
качество, независимость происхождения кода или степень готовности эмулятора.

## Что действительно сообщается о запусках

- [SharpEmu](https://sharpemu.app/) показывает 86 проверенных записей, из которых
  32 помечены Playable и 16 Ingame. Это снимок общественного каталога, а не
  процент всей библиотеки PS5. [Kitaria Fables](https://github.com/sharpemu/sharpemu-site/issues/260)
  помечена playable на `b02c061`, Windows, 5800X3D/4070S; подробное текстовое
  описание ограничений в этом отчёте отсутствует.
- [GTA V в KytyPS5, #888](https://github.com/KytyPS5/KytyPS5/issues/888): сообщается
  о выходе в открытый мир, 10–20 FPS в Windows и 20–30 FPS в прологе Linux
  на Ryzen 7 5700/RTX 4060. Есть исчезающие объекты, неверные колёса и регрессия
  запуска в новых Windows-сборках. Это in-game, а не стабильное прохождение.
- [prosper: совместимость](https://github.com/mattias800/prosper/blob/main/COMPATIBILITY.md)
  содержит игровые сцены The Messenger, Dead Cells, Blasphemous 2 и других,
  а также GTA V в прологе. Для 3D перечислены конкретные дефекты. Начальная
  игровая сцена не подтверждает полную проходимость.
- [AnyPS5: таблица проверенных игр](https://github.com/boykopovar/AnyPS5/blob/main/docs/user/COMPATIBILITY.md)
  сейчас содержит Dreaming Sarah с playable и 60 FPS на GTX 1050 Ti/i5-7500.
  Маркетинговые заявления о многих играх нельзя автоматически переносить в
  эту таблицу.
- [Prosperity README](https://github.com/Force67/prosperity) демонстрирует PS5
  Dead Cells, Isaac, Minecraft и меню Skyrim. Требования Linux включают 8 ГБ
  VRAM и Vulkan 1.4: наша GTX 1060 3 ГБ ниже заявленного объёма памяти.
- [PS5PCEM: статус](https://github.com/iStark/PS5PCEM/blob/main/docs/project-status.md)
  вместе с README различает gameplay и экспериментальные сцены. Например,
  сцена Ghost of Yotei при 0,6 FPS прямо обозначена как непригодная для игры.

## Особенно полезная ветка GTA V

[TheCruZ/KytyPS5-GTA](https://github.com/TheCruZ/KytyPS5-GTA) — ветка с
исправлениями для PS5-версии GTA V. Автор сообщает о завершении пролога и
Лос-Сантосе; около 35 FPS в плотных районах и до 60 в части сцен на
RTX 3090/Ryzen 9 5900X. Это его результат, не прогноз для GTX 1060.
Репозиторий описывает исправления шейдеров, потоков и производительности,
часть передаётся в основную ветку. При проверке: `21616e2cdf`, 08.10 UTC;
последний релиз [v7](https://github.com/TheCruZ/KytyPS5-GTA/releases/tag/v7).
GTA V полезна как близкий по движку ориентир, но её работа не доказывает GTA VI.

## Дополнительные ветки и старые проекты

- [KytyPlus](https://github.com/Coder787-source/KytyPlus): производный проект,
  отдельные улучшения совместимости, последний коммит `d7e9d9632a`, 08.10 UTC.
- [BryKytyPS5](https://github.com/BryanKAdams/BryKytyPS5): ветка KytyPS5,
  `a9e1ae5d91`, 04.10 UTC. Не считать её отдельным независимым движком.
- [Оригинальный Kyty](https://github.com/InoriRus/Kyty): последний коммит
  основной ветки по API датирован 03.10.2022. Важен исторически; активный
  KytyPS5 — другой репозиторий.

У SharpEmu официальным сайтом назван только `sharpemu.app` и каналы из README.
`sharpemu.dev` не следует считать официальным источником его достижений.
Эмуляторы PS1/PS3/Switch, работающие НА PS5, не запускают PS5-игры НА ПК.

## Вывод для TouchePX5

Мы не единственные и не впереди публичной сцены по показанной совместимости:
наш проверенный сценарий — модифицированный homebrew Wolf, тогда как другие
публикуют запуски коммерческих PS5-игр. Это разные входные программы и условия.

Наиболее полезный следующий исследовательский шаг: сравнить наш базовый
SharpEmu-код с текущим upstream; отдельно проверить наш независимый GPU-вход
на KytyPS5 и изучить исправления GTA-ветки по реальным ошибкам. Не переносить
код без проверки поведения и лицензии, не заменять работающий проект вслепую.

Надёжного публичного доказательства комфортного запуска GTA VI на ПК через
эмуляцию в просмотренных материалах не найдено. Отсутствие найденного отчёта
не доказывает отсутствие всех закрытых исследований.
